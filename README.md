
# 🚀 Tasks Flask CRUD API

API RESTful desenvolvida em Python com Flask para gerenciamento de tarefas, estruturada com o padrão de Blueprints e persistência de dados utilizando SQLAlchemy e SQLite. Projeto criado com foco em boas práticas, arquitetura modular e código limpo para portfólio.

---

## 🛠️ Tecnologias Utilizadas

* **Python 3.x**
* **Flask** (Microframework web)
* **Flask-SQLAlchemy** (ORM para gerenciamento do banco de dados)
* **SQLite** (Banco de dados relacional leve para persistência)
* **Postman** (Testes de API)
